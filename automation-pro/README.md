### 📊 استانداردهای حقوق و دستمزد ۱۴۰۵

```php
// مقادیر پیش‌فرض (قابل بروزرسانی از پنل تنظیمات)
[
    'base_salary' => 2,388,000,      // حقوق پایه ماهانه
    'housing_allowance' => 900,000,  // حق مسکن
    'food_allowance' => 1,400,000,   // بن خواربار
    'child_allowance' => 716,400,    // حق اولاد (هر فرزند)
    'spouse_allowance' => 500,000,   // حق عائله‌مندی
    'overtime_rate' => 159,200,      // نرخ هر ساعت اضافه‌کاری
    'night_shift_bonus' => 35,       // درصد فوق‌العاده شب‌کاری
    'holiday_bonus' => 40,           // درصد فوق‌العاده تعطیل‌کاری
    'insurance_ceiling' => 45,000,000, // سقف مشمول بیمه
    'insurance_employee' => 7,       // درصد سهم کارمند
    'insurance_employer' => 23,      // درصد سهم کارفرما
]
```

#### پله‌های مالیاتی ۱۴۰۵:
| محدوده درآمد (ریال) | نرخ مالیات |
|---------------------|------------|
| 0 - 12,000,000 | 0% |
| 12,000,001 - 18,000,000 | 10% |
| 18,000,001 - 30,000,000 | 15% |
| 30,000,001 - 50,000,000 | 20% |
| 50,000,001 - 100,000,000 | 25% |
| بالای 100,000,000 | 30% |

### 🚀 نصب و راه‌اندازی

#### پیش‌نیازها:
- PHP 8.1 یا بالاتر
- MySQL 8.0 یا بالاتر / MariaDB 10.6+
- Redis (اختیاری برای کش)
- Composer (برای مدیریت وابستگی‌ها)

#### مراحل نصب:

```bash
# 1. استخراج فایل ZIP
unzip automation-pro-v2.0-enterprise.zip -d /var/www/html/

# 2. ایجاد پایگاه داده
mysql -u root -p < automation-pro/database.sql

# 3. تنظیمات اتصال به دیتابیس
# ویرایش فایل config/database.php یا استفاده از متغیرهای محیطی
export DB_HOST=localhost
export DB_DATABASE=automation_pro
export DB_USERNAME=root
export DB_PASSWORD=your_password

# 4. تنظیم مجوزها
chmod -R 777 automation-pro/storage/
chmod -R 777 automation-pro/public/uploads/
chmod -R 777 automation-pro/plugins/

# 5. ورود به سیستم
# URL: http://localhost/automation-pro
# نام کاربری: admin
# رمز عبور: admin123
```
