## 🚀 نصب و راه‌اندازی

### پیش‌نیازها
- PHP 8.0 یا بالاتر
- MySQL 5.7 یا بالاتر (یا MariaDB 10.3+)
- Web Server (Apache/Nginx)
- افزونه‌های PHP: PDO, JSON, MBString, OpenSSL

### مراحل نصب

#### 1. استخراج فایل ZIP
```bash
unzip automation-pro-v4.0-enterprise.zip -d /var/www/html/
cd /var/www/html/automation-v4.0
```

#### 2. ایجاد پایگاه داده
```bash
mysql -u root -p < database.sql
```

یا به صورت دستی:
```sql
CREATE DATABASE automation_pro CHARACTER SET utf8mb4 COLLATE utf8mb4_persian_ci;
```

#### 3. تنظیمات اتصال به دیتابیس
فایل `config/database.php` را ویرایش کنید:
```php
return [
    'host' => 'localhost',
    'port' => '3306',
    'database' => 'automation_pro',
    'username' => 'root',
    'password' => 'your_password',
    // ...
];
```

یا از متغیرهای محیطی استفاده کنید:
```bash
export DB_HOST=localhost
export DB_NAME=automation_pro
export DB_USER=root
export DB_PASS=your_password
```

#### 4. تنظیم مجوزها
```bash
chmod -R 777 uploads/
chmod -R 777 plugins/
chown -R www-data:www-data .
```

#### 5. ورود به سیستم
- آدرس: `http://localhost/automation-v4.0`
- نام کاربری: `admin`
- رمز عبور: `admin123`

**⚠️ توجه:** حتماً پس از اولین ورود رمز عبور را تغییر دهید!

## 💰 استانداردهای حقوق و دستمزد 1405

### مقادیر پیش‌فرض سال 1405

| عنوان | مبلغ (ریال) | توضیحات |
|-------|-------------|---------|
| حقوق پایه ماهانه | 85,000,000 | حداقل حقوق پایه |
| حق مسکن | 25,000,000 | کمک هزینه مسکن |
| بن خواربار | 15,000,000 | کمک هزینه معیشت |
| حق اولاد | 10% پایه | به ازای هر فرزند (حداکثر 4) |

### ضرایب محاسباتی

| عنوان | ضریب | توضیحات |
|-------|------|---------|
| اضافه کاری عادی | 1.40 | 40% اضافه بر نرخ ساعت |
| شب کاری | 1.60 | 60% اضافه (بدون نوبت) |
| تعطیل کاری | 2.00 | دو برابر نرخ ساعت |

### بیمه

| عنوان | درصد | توضیحات |
|-------|------|---------|
| سهم کارمند | 7% | کسر از حقوق |
| سهم کارفرما | 23% | هزینه کارفرما |

### مالیات پلکانی 1405

| سقف ماهانه (ریال) | نرخ |
|-------------------|-----|
| تا 120,000,000 | 0% |
| 120,000,000 - 160,000,000 | 10% |
| 160,000,000 - 220,000,000 | 15% |
| 220,000,000 - 300,000,000 | 20% |
| بالای 300,000,000 | 25% |

### بروزرسانی برای سال جدید

برای بروزرسانی نرخ‌ها به سال جدید، کافی است:

```sql
UPDATE ap_salary_standards 
SET is_active = 0 
WHERE year = 1405;

INSERT INTO ap_salary_standards (year, base_salary, housing_allowance, food_allowance, tax_brackets) 
VALUES (1406, [new_values]);
```

یا از طریق پنل مدیریت > تنظیمات > استانداردهای حقوق اقدام کنید.

```php
$review = AIAssistant::generatePerformanceReview($employeeId, $period);
```

```php
$recommendations = AIAssistant::recommendTraining($employeeId);
```

```php
$response = AIAssistant::answerHRQuestion($question, $context);
```

```php
$forecast = AIAssistant::forecastHeadcount($departmentId, $months);
```

```php
$jd = AIAssistant::generateJobDescription($positionTitle, $requirements);
```

## 🔌 سیستم پلاگین‌محور

### ساختار پلاگین

```
plugins/
└── plugin-name/
    ├── plugin.json          # Manifest پلاگین
    ├── plugin-name.php      # فایل اصلی
    ├── install.php          # نصب‌کننده
    ├── activate.php         # فعال‌سازی
    ├── deactivate.php       # غیرفعال‌سازی
    ├── uninstall.php        # حذف
    ├── views/               # قالب‌ها
    ├── assets/              # CSS, JS, تصاویر
    ├── includes/            # کلاس‌ها
    └── languages/           # ترجمه
```

### نمونه plugin.json

```json
{
    "name": "ارزیابی 360 درجه",
    "slug": "360-evaluation",
    "version": "1.0.0",
    "description": "سیستم ارزیابی عملکرد 360 درجه",
    "author": "شرکت شما",
    "requires_php": "8.0",
    "dependencies": ["core>=4.0"],
    "menu": [
        {
            "title": "ارزیابی 360",
            "url": "/plugins/360-evaluation/index.php",
            "icon": "users",
            "permission": "hr"
        }
    ],
    "hooks": {
        "before_payroll_calc": "calculate_bonus",
        "after_hire": "send_welcome_email"
    }
}
```

| `after_hire` | بعد از استخدام | employee_id |
| `before_termination` | قبل از قطع همکاری | employee_id |

## 🔒 امنیت

### لایه‌های امنیتی

1. **SQL Injection Protection**
   - استفاده از Prepared Statements در تمام کوئری‌ها
   - Validation ورودی‌ها

2. **CSRF Protection**
   - توکن‌های یکتا برای هر فرم
   - بررسی خودکار در تمام POST requests

3. **XSS Prevention**
   - Sanitization خروجی‌ها
   - Content Security Policy headers

4. **Password Security**
   - هش کردن با bcrypt (cost=12)
   - سیاست رمز عبور قوی
   - انقضای رمز عبور

5. **Session Security**
   - Session fixation protection
   - Secure & HttpOnly cookies
   - Session timeout

6. **Access Control**
   - RBAC (Role-Based Access Control)
   - Permission-based authorization
   - Audit logging

7. **2FA Support**
   - TOTP-based two-factor authentication
   - Backup codes

### لاگ و مانیتورینگ

- لاگ تمام ورودها (موفق/ناموفق)
- لاگ تغییرات مهم (activity logs)
- هشدار ورودهای مشکوک
- Rate limiting

## 📡 APIها

### REST API (در حال توسعه)

```
GET    /api/v1/employees          # لیست کارکنان
POST   /api/v1/employees          # ایجاد کارمند جدید
GET    /api/v1/employees/{id}     # جزئیات کارمند
PUT    /api/v1/employees/{id}     # بروزرسانی کارمند
DELETE /api/v1/employees/{id}     # حذف کارمند

GET    /api/v1/payrolls           # لیست فیش‌های حقوقی
POST   /api/v1/payrolls/calculate # محاسبه حقوق

GET    /api/v1/attendance         # سجلات حضور
POST   /api/v1/attendance/checkin # ثبت ورود
POST   /api/v1/attendance/checkout # ثبت خروج

GET    /api/v1/leave-requests     # درخواست‌های مرخصی
POST   /api/v1/leave-requests     # ثبت درخواست مرخصی

POST   /api/v1/ai/analyze         # درخواست تحلیل هوش مصنوعی
```
