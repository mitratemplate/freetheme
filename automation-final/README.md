## 🚀 نصب و راه‌اندازی

### پیش‌نیازها
- PHP 8.0 یا بالاتر
- MySQL 8.0 یا بالاتر
- Web Server (Apache/Nginx)
- Extension های PDO, curl, mbstring

### مراحل نصب

#### 1. استخراج فایل ZIP
```bash
unzip automation-final.zip -d /var/www/html/
cd /var/www/html/automation-final
```

#### 2. ایجاد پایگاه داده
```bash
mysql -u root -p < database.sql
```

یا به صورت دستی:
```sql
CREATE DATABASE automation_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

#### 3. تنظیمات اتصال به دیتابیس
فایل `config/database.php` را ویرایش کنید:
```php
return [
    'host' => 'localhost',
    'dbname' => 'automation_db',
    'username' => 'root',
    'password' => 'YOUR_PASSWORD',
    // ...
];
```

#### 4. تنظیم مجوزها
```bash
chmod -R 755 automation-final/
chmod -R 777 automation-final/uploads/
chmod -R 777 automation-final/logs/
```

#### 5. تنظیم API Key هوش مصنوعی (اختیاری)
```bash
export GAPGPT_API_KEY="your-api-key-here"
```

#### 6. ورود به سیستم
- آدرس: `http://localhost/automation-final`
- نام کاربری: `admin`
- رمز عبور: `admin123`

```sql

    base_salary = NEW_VALUE,
    housing_allowance = NEW_VALUE,
    -- ...
WHERE year = 1406;
```

## 🤖 هوش مصنوعی

### اتصال به GapGPT

سیستم از API سایت `gapgpt.app` استفاده می‌کند.

### حوزه‌های تخصصی

1. **عمومی** (`general`) - پاسخ به سوالات کلی درباره سیستم
2. **تحلیل HR** (`hr_analysis`) - تحلیل آمار کارکنان، ترک خدمت
3. **حقوق و دستمزد** (`payroll`) - محاسبات، بیمه، مالیات
4. **استخدام** (`recruitment`) - تحلیل رزومه، سوالات مصاحبه
5. **ارزیابی عملکرد** (`performance`) - KPI، بازخورد
6. **مشاوره حقوقی** (`legal`) - قوانین کار، قراردادها

### نمونه سوالات

```
- نرخ بیمه و مالیات برای حقوق ۱۰۰ میلیون تومان چقدر است؟
- چگونه می‌توانم نرخ ترک خدمت را تحلیل کنم؟
- برای مصاحبه برنامه‌نویس PHP چه سوالاتی بپرسم؟
- فرمول محاسبه اضافه کاری طبق قانون کار چیست؟
```

## 🔐 امنیت

### لایه‌های امنیتی

1. **SQL Injection Prevention**
   - استفاده از Prepared Statements در تمام کوئری‌ها
   - Validation ورودی‌ها

2. **CSRF Protection**
   - توکن تصادفی برای هر session
   - بررسی توکن در تمام فرم‌ها

3. **XSS Prevention**
   - Escape خروجی‌ها با `htmlspecialchars()`
   - Sanitization ورودی‌ها

4. **Password Security**
   - هش با bcrypt (cost=10)
   - حداقل طول رمز ۸ کاراکتر

5. **Access Control**
   - سیستم RBAC (Role-Based Access Control)
   - بررسی دسترسی در هر درخواست

6. **Audit Logging**
   - ثبت تمام فعالیت‌های کاربران
   - IP Address و User Agent

## 🔌 توسعه پلاگین

### ساختار پلاگین

```
plugins/
└── your-plugin/
    ├── plugin.json          # Manifest پلاگین
    ├── your-plugin.php      # فایل اصلی
    ├── install.php          # نصب
    ├── activate.php         # فعال‌سازی
    ├── deactivate.php       # غیرفعال‌سازی
    ├── uninstall.php        # حذف
    ├── views/               # قالب‌ها
    ├── assets/              # CSS, JS
    └── includes/            # کلاس‌ها
```

### نمونه plugin.json

```json
{
    "name": "گزارش‌گیری پیشرفته",
    "slug": "advanced-reports",
    "version": "1.0.0",
    "author": "شرکت شما",
    "description": "سیستم گزارش‌گیری با نمودارهای پیشرفته",
    "requires": "3.0",
    "hooks": {
        "before_payroll_calc": "calculate_bonus",
        "after_employee_add": "send_welcome_email"
    },
    "menus": [
        {
            "title": "گزارش‌ها",
            "url": "advanced-reports",
            "icon": "chart-bar"
        }
    ]
}
```

### هوک‌های موجود

- `before_payroll_calc` - قبل از محاسبه حقوق
- `after_payroll_calc` - بعد از محاسبه حقوق
- `before_employee_save` - قبل از ذخیره کارمند
- `after_employee_save` - بعد از ذخیره کارمند
- `on_leave_request` - هنگام درخواست مرخصی
- `daily_attendance_report` - گزارش روزانه حضور
