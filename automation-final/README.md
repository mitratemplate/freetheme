### 🎯 معرفی

سامانه جامع اتوماسیون اداری و مدیریت منابع انسانی، طراحی شده بر اساس استانداردهای کار ایران سال ۱۴۰۵ با استفاده از:
- **PHP 8+** برای بک‌اند
- **MySQL 8+** برای پایگاه داده

### 🚀 نصب و راه‌اندازی

#### پیش‌نیازها:
- PHP 8.0 یا بالاتر
- MySQL 8.0 یا بالاتر
- وب‌سرور (Apache/Nginx)
- اکستنشن‌های PDO, MBString, JSON

#### مراحل نصب:

```bash
# 1. استخراج فایل ZIP
unzip automation-enterprise-v5.0.zip -d /var/www/html/automation
cd /var/www/html/automation

# 2. ایجاد پایگاه داده
mysql -u root -p < database.sql

# 3. تنظیمات اتصال به دیتابیس
# ویرایش فایل config/database.php
nano config/database.php

# 4. تنظیم مجوزها
chmod -R 755 .
chmod -R 777 uploads/
chmod -R 777 plugins/

# 5. تنظیم وب‌سرور (Apache)
# ایجاد VirtualHost یا انتقال به public_html
```

#### ورود به سامانه:
```
URL: http://localhost/automation/modules/auth/login.php
نام کاربری: admin
رمز عبور: admin123
```

### 💰 استانداردهای حقوق و دستمزد ۱۴۰۵

#### مقادیر پیش‌فرض (قابل بروزرسانی):
| عنوان | مقدار (ریال) |
|-------|-------------|
| حقوق پایه روزانه | 2,386,000 |
| حق مسکن ماهانه | 9,000,000 |
| بن خواربار ماهانه | 1,400,000 |
| حق اولاد (هر فرزند) | 714,000 |
| حداقل حقوق ماهانه | 35,000,000 |
| نرخ هر ساعت اضافه کاری | 145,000 |

#### جدول مالیاتی پلکانی:
| محدوده درآمد (ریال) | درصد مالیات |
|---------------------|------------|
| 0 - 12,000,000 | 0% |
| 12,000,001 - 16,000,000 | 10% |
| 16,000,001 - 25,000,000 | 15% |
| 25,000,001 - 100,000,000 | 20% |

#### بروزرسانی برای سال جدید:
برای بروزرسانی استانداردها در سال جدید، کافیست مقادیر جدول `salary_standards` را در دیتابیس تغییر دهید:

```sql
UPDATE salary_standards SET 
    base_salary = 3000000,
    housing_allowance = 10000000,
    -- سایر مقادیر
WHERE year = 1406;
```

### 🔒 امنیت

#### لایه‌های امنیتی:
1. **SQL Injection Prevention** - Prepared Statements با PDO
2. **CSRF Protection** - توکن‌های امنیتی برای تمام فرم‌ها
3. **XSS Prevention** - Sanitize کردن تمام ورودی‌ها
4. **Password Hashing** - bcrypt با cost factor بالا
5. **Session Security** - مدیریت امن سشن‌ها
6. **Role-Based Access Control** - سیستم نقش و دسترسی
7. **Input Validation** - اعتبارسنجی کامل ورودی‌ها

#### بهترین روش‌ها:
- غیرفعال کردن display_errors در محیط تولید
- استفاده از HTTPS
- بروزرسانی منظم PHP و MySQL
- پشتیبان‌گیری دوره‌ای از دیتابیس
- محدود کردن دسترسی به فایل‌های حساس
