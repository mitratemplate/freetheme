# سیستم اتوماسیون اداری - ویژه شرکت‌های ایرانی (سال ۱۴۰۵)

## معرفی
این سیستم یک راهکار جامع برای مدیریت منابع انسانی، حقوق و دستمزد، حضور و غیاب و سایر فرآیندهای اداری مطابق با استانداردهای کار ایران در سال ۱۴۰۵ می‌باشد.

## ویژگی‌های اصلی

### ۱. مدیریت کارکنان
- ثبت اطلاعات کامل پرسنلی
- مدیریت سوابق تحصیلی و شغلی
- دسته‌بندی بر اساس واحدهای سازمانی
- انواع قرارداد (رسمی، قراردادی، موقت، پاره‌وقت)

### ۲. حقوق و دستمزد
- محاسبه خودکار حقوق بر اساس استانداردهای سال ۱۴۰۵
- محاسبه اضافه کاری، شب کاری و تعطیل کاری
- کسر بیمه و مالیات به صورت خودکار
- قابلیت بروزرسانی سالانه نرخ‌ها
- تولید فیش حقوقی

### ۳. حضور و غیاب
- ثبت ورود و خروج
- محاسبه تاخیر و تعجیل
- مدیریت اضافه کاری
- انواع مرخصی (استحقاقی، استعلاجی، بدون حقوق و...)

### ۴. وام و مساعده
- درخواست وام و مساعده
- مدیریت اقساط
- کسر از حقوق

### ۵. گزارشات
- گزارش حقوق و دستمزد
- گزارش حضور و غیاب
- گزارش مرخصی‌ها
- خروجی اکسل

## نصب و راه‌اندازی

### پیش‌نیازها
- سرور وب (Apache/Nginx)
- PHP 8.0 یا بالاتر
- MySQL 8.0 یا بالاتر
- Composer (اختیاری)

### مراحل نصب

1. **ایجاد پایگاه داده**
```bash
mysql -u root -p < database.sql
```

2. **تنظیمات اتصال به پایگاه داده**
فایل `config/database.php` را ویرایش کرده و اطلاعات اتصال را وارد کنید:
```php
return [
    'host' => 'localhost',
    'database' => 'office_automation',
    'username' => 'root',
    'password' => 'your_password',
];
```

3. **تنظیم دسترسی‌ها**
```bash
chmod -R 755 /path/to/automation
```

4. **ورود به سیستم**
- آدرس: `http://your-domain/automation`
- نام کاربری پیش‌فرض: `admin`
- رمز عبور پیش‌فرض: `admin123`

## بروزرسانی سالانه

برای بروزرسانی استانداردهای حقوق و دستمزد برای سال جدید:

1. افزودن سال جدید در جدول `years`
2. بروزرسانی مقادیر در جدول `salary_standards`
3. فعال کردن سال جدید

```sql
-- مثال: افزودن سال ۱۴۰۶
INSERT INTO years (year_shamsi, year_miladi, is_active) VALUES ('1406', '2027', FALSE);

-- بروزرسانی استانداردها
UPDATE salary_standards SET 
    base_salary = new_value,
    daily_allowance = new_value,
    -- ...
WHERE year_id = (SELECT id FROM years WHERE year_shamsi = '1406');
```

## امنیت
