## 🏢 ماژول‌های سیستم

### ۱. مدیریت کارکنان (HR Management)
- **اطلاعات پرسنلی کامل**
  - مشخصات فردی و تماس
  - سوابق تحصیلی و گواهینامه‌ها
  - سوابق کاری و مراجع
  - مهارت‌ها و تخصص‌ها
  - اطلاعات بانکی و بیمه
  
- **مدیریت قراردادها**
  - انواع قرارداد (دائم، موقت، پروژه‌ای، پاره‌وقت)
  - دوره آزمایشی
  - تاریخ شروع و پایان
  - تمدید و فسخ قرارداد

### ۲. جذب و استخدام (Recruitment)
- **مدیریت موقعیت‌های شغلی**
  - تعریف موقعیت‌های شغلی
  - شرایط احراز و مسئولیت‌ها
  - محدوده حقوقی
  
- **آگهی‌های استخدامی**
  - انتشار آگهی
  - تعیین مهلت درخواست
  - مدیریت ظرفیت
  
- **متقاضیان**
  - ثبت رزومه و اطلاعات
  - وضعیت خدمت سربازی
  - منبع جذب
  - معرفی توسط کارکنان
  
- **مصاحبه‌ها**
  - زمان‌بندی مصاحبه
  - انواع مصاحبه (تلفنی، حضوری، فنی، HR)
  - معیارهای ارزیابی
  - امتیازدهی و بازخورد
  - توصیه نهایی

### ۳. ارزیابی عملکرد (Performance Management)
- **چرخه‌های ارزیابی**
  - ماهانه، فصلی، نیمساله، سالانه
  - تعیین بازه زمانی
  
- **شاخص‌های کلیدی عملکرد (KPI)**
  - تعریف KPIهای فردی، تیمی، واحد
  - اهداف کمی و کیفی
  
- **اهداف کارکنان**
  - تعیین اهداف هر دوره
  - وزن‌دهی به اهداف
  - پیگیری پیشرفت
  - ارزیابی نهایی
  
- **ارزیابی ۳۶۰ درجه**
  - خودارزیابی
  - ارزیابی مدیر
  - ارزیابی همکاران
  - ارزیابی زیردستان
  - نقاط قوت و زمینه‌های بهبود
  - برنامه توسعه فردی

### ۴. آموزش و توسعه (Training & Development)
- **دوره‌های آموزشی**
  - داخلی و خارجی
  - حضوری، آنلاین، ترکیبی
  - هزینه و مدت زمان
  - ظرفیت شرکت‌کنندگان
  
- **ثبت‌نام و پیگیری**
  - وضعیت شرکت در دوره
  - آزمون قبل و بعد
  - درصد حضور
  - گواهینامه‌ها
  
- **نیازسنجی آموزشی**
  - شناسایی شکاف مهارتی
  - اولویت‌بندی نیازها
  - تایید و بودجه‌بندی

### ۵. اموال و تجهیزات (Asset Management)
- **انواع اموال**
  - الکترونیکی، مبلمان، خودرو، نرم‌افزار
  - نرخ استهلاک
  - عمر مفید
  
- **مدیریت اموال**
  - کدینگ و شناسه یکتا
  - مشخصات کامل
  - محل استقرار
  - وضعیت (موجود، تخصیص یافته، تعمیر، بازنشسته)
  
- **تاریخچه اموال**
  - تخصیص به کارکنان
  - انتقال بین واحدها
  - تعمیر و نگهداری
  - بازگشت

### ۶. وام‌ها و مساعده (Loans & Advances)
- **انواع وام**
  - وام ضروری، خرید کالا، مسکن، خودرو
  - سقف مبلغ و اقساط
  - نرخ سود
  
- **درخواست وام**
  - ثبت درخواست
  - مراحل تایید
  - پرداخت
  
- **اقساط**
  - جدول amortization
  - سررسید اقساط
  - وضعیت پرداخت
  - کسر از حقوق

### ۷. حضور و غیاب (Attendance)
- **شیفت‌های کاری**
  - صبح، ظهر، شب، چرخشی
  - ساعت شروع و پایان
  - زمان استراحت
  - مهلت ورود
  
- **برنامه کاری**
  - روزهای کاری هفته
  - شیفت اختصاصی
  - برنامه منعطف
  
- **تردد روزانه**
  - ثبت ورود و خروج
  - ساعات کارکرد
  - اضافه کاری
  - تاخیر و تعجیل
  - تایید توسط مدیر

### ۸. مرخصی‌ها (Leave Management)
- **انواع مرخصی**
  - استحقاقی (۲۶ روز سالانه)
  - استعلاجی (با گواهی پزشک)
  - بدون حقوق
  - ازدواج (۳ روز)
  - فوت (۳ روز)
  - زایمان (۹۰ روز)
  - ساعتی
  
- **مانده مرخصی**
  - محاسبه accrual ماهانه
  - استفاده شده
  - انتقال به سال بعد (حداکثر ۹ روز)
  - سوخت شده
  
- **درخواست مرخصی**
  - ثبت درخواست
  - تعیین جانشین
  - بارگذاری مدارک
  - تایید مدیر
  - تقویم مرخصی‌ها

### ۹. ماموریت‌ها (Missions)
- **ثبت ماموریت**
  - مقصد و هدف
  - مدت زمان
  - وسیله نقلیه
  - هزینه تخمینی
  - علی‌الحساب
  
- **پیگیری**
  - گزارش ماموریت
  - هزینه واقعی
  - تسویه حساب

### ۱۰. حقوق و دستمزد (Payroll)
- **محاسبات حقوق**
  - حقوق پایه
  - حق مسکن و خواربار
  - حق اولاد (حداکثر ۲ فرزند)
  - اضافه کاری (ضریب ۱.۴)
  - شب کاری (ضریب ۱.۱۵)
  - تعطیل کاری (ضریب ۱.۴)
  - پاداش و کمیسیون
  
- **کسورات**
  - بیمه سهم کارمند (۷٪)
  - مالیات پلکانی
  - اقساط وام
  - مساعده
  - کسر کار
  
- **فیش حقوقی**
  - ناخالص و خالص
  - جزئیات کامل
  - وضعیت پرداخت
  - سابقه پرداخت

### ۱۱. گزارشات (Reports)
- گزارش‌های منابع انسانی
- گزارش‌های حقوق و دستمزد
- گزارش‌های حضور و غیاب
- گزارش‌های ارزیابی
- داشبورد مدیریتی

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها
- PHP 8.0+
- MySQL 8.0+ یا MariaDB 10.5+
- Web Server (Apache/Nginx)

### مراحل نصب

۱. **کلون کردن پروژه**
```bash
cd /workspace
```

۲. **ایجاد پایگاه داده**
```bash
mysql -u root -p < automation/database.sql
```

۳. **تنظیمات اتصال به دیتابیس**
فایل `config/database.php` را ویرایش کنید:
```php
<?php
define('DB_HOST', 'localhost');
define('DB_NAME', 'automation_db');
define('DB_USER', 'root');
define('DB_PASS', '');
define('DB_CHARSET', 'utf8mb4');
```

۴. **تنظیم دسترسی‌ها**
```bash
chmod -R 755 automation/
chmod -R 777 automation/uploads/
```

۵. **ورود به سیستم**
- آدرس: `http://localhost/automation`
- نام کاربری: `admin`
- رمز عبور: `admin123`
